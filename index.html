Seller · Atomic Offers

Accepting an offer creates an on-chain ZB-1 atomic lock. Once the lock confirms, the seller cannot cancel or manually transfer the NFT through this client until settlement or expiry.

Connect Noir Wallet to load offers.

Buyer · Atomic Checkout

Payment opens only after the seller lock is confirmed. The settlement is valid only when one Zcash transaction contains the exact 97% seller output + 3% treasury output.

Your locked atomic purchases will appear here.
Atomic rule: seller authorization is locked first. A valid payment transaction deterministically moves the ZEC BLOCK to the designated buyer — no final seller approval is required.
Wallet requirement: Noir Wallet's current browser API cannot create a multi-recipient transaction. Do not send two separate payments. Atomic checkout must be executed by a wallet that creates the generated ZIP-321 multi-payment request as one Zcash transaction, then paste that TXID here for verification.

List ZEC BLOCK

Listings are signed marketplace intents mirrored across multiple public relays. Website updates do not erase the listing; the client reconstructs it from relay events. Listing does not transfer the NFT or move ZEC.

Make Offer

Offers are signed intents only. If the seller accepts, the NFT is locked on Zcash before any payment request becomes active.

Transfer ZEC BLOCK

Transfers are irreversible protocol events. Verify the recipient commitment carefully before approving the Zcash transaction.
